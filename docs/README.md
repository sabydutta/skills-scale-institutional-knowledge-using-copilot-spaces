# OctoAcme Project Management Docs

This directory consolidates the project management processes used by OctoAcme and provides quick access to the team’s standard guidance for managing work from idea to release. OctoAcme follows an iterative, customer-first approach with clear roles, defined artifacts, and a steady delivery cadence to reduce risk and deliver measurable outcomes.

Brief overview:

OctoAcme projects move through a lightweight lifecycle: Initiation (validate problem, stakeholders, and success metrics), Planning (prioritize work, estimate, and identify dependencies), Execution & Tracking (implement in small increments with CI, reviews, and metrics), Release & Deployment (pre-release checks, automated pipelines, and rollback plans), and Continuous Improvement (retrospectives, action items, and tracking). Core roles include Product Managers (define outcomes), Project Managers (coordinate delivery and communication), Developers (build and test), and QA (validate acceptance criteria). Key artifacts are the Project One-pager, Roadmap/Release Plan, Backlog with acceptance criteria, Risk Register, and Retrospective action items.

## How to Use This Folder

Use this directory as the single entry point for OctoAcme’s project management guidance. Start with the overview and initiation guide for new work, then move into planning and execution docs as you prepare and deliver features. Keep the Project One-pager and Risk Register updated in the repo and link important decisions in the project README for visibility.
